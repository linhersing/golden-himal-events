# Golden Himal Voice｜尼泊爾現場評審手機操作驗收（2026年11月18日）

本文件是主辦與評審的 **UAT 驗收基準**，並非宣稱已完成任何實機測試。本案不能假設尼泊爾現場所有評審使用相同品牌、螢幕、瀏覽器或網路。

## 設計邊界

- **一位選手一筆名冊**；評審進入時一次只顯示一首作品及其對應的評分表，避免五份表單同時排列。
- 真正的現場第二輪、第三輪評分使用既有後端 `score` 流程，初賽逐首評分使用 `january-video-score`；不能混用兩者，也不能改寫既有評審分數或歷史。
- **伺服器回應確認才可顯示「儲存成功」**。送出期間禁用儲存按鈕避免連點，失敗/斷線保留畫面已輸入分數；請查核後才再次操作。若 request timeout，無法僅靠客戶端判定伺服器是否已寫入，不能自動重送。
- 沒有實際離線評分同步系統。本版不可宣稱「離線仍能儲存」；不得將評分/身份資料無授權寫入 LocalStorage。
- 不降低評審/主辦登入安全、OTP/Turnstile、角色權限限制、伺服器的評分唯一性及不可覆蓋稽核。

## 建議驗收矩陣

| 項目 | 必測條件 | 合格判準 |
| --- | --- | --- |
| 視窗寬度 | 280、320、360、375、390、412、430、480、768 CSS px | 不水平捲動；按鈕/輸入可見且能點擊；標題與長歌名能換行 |
| 方向 | 直式手機、橫式低高度 740×360 | 選單/評分可操作；焦點不被鍵盤擋住 |
| 字體 | 一般、系統字體放大、瀏覽器文字200% | 不截斷重要數字、錯誤訊息、歌曲名稱 |
| 裝置 | 至少兩種不同廠牌 Android，含一支較舊／低階機；另選 iOS Safari（如評審使用） | 觸控輸入、下拉選單、數字鍵盤與提交操作正常 |
| 瀏覽器 | Android Chrome、Samsung Internet 或當地實際使用瀏覽器；有使用 iPhone 則Safari | 非僅桌機 Chrome 模擬；真機可登入及評分 |
| 網路 | 穩定 Wi-Fi、行動網路高延遲/不穩、送出時斷線、逾時 | 同筆分數不可重複寫入；狀態不明時不宣稱成功、不自動重送 |
| 多首 | 同一參賽者 1、3、5 首；切換第 2～5 首 | 只顯示目前選取的一首；分數寫到對應 position，切換不丟草稿 |
| 現場評分 | 四個現場評分項目+利益衝突勾選 | 每個範圍正確、可觸控、無漏填、成功確認且無權限越界 |
| 高人數 | 20、100 位合成參賽者；多次搜尋/篩選/分頁 | 名冊不卡頓、主辦找到正確選手；大規模伺服器端分頁另外追蹤Issue #89 |
| 容錯 | 連點提交、重複刷新、重新登入、連線恢復 | 依照後端真實資料顯示已評/待評，失敗保留輸入並可安全查核 |
