# Private draft release checklist

- [x] Repository visibility is Private.
- [x] GitHub Pages is not enabled.

- [x] Privacy scan reports zero findings in source and build output.

- [x] No unapproved date, prize, schedule, organizer, judging, or partner claim is present.

## Experience

- [x] Desktop 1440×900 has no horizontal overflow.
- [x] Tablet 768×1024 has no overlapping cards or controls.
- [x] Mobile 390×844 is readable without horizontal scrolling.
- [x] Keyboard focus, labels, alternative text, and status announcements are present.

## Functionality

- [x] Registration remains preview-only.
- [x] No Email, database, webhook, payment, analytics, or remote form call occurs.
- [x] Production build and all automated checks pass.
